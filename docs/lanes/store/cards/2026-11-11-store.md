# Card: the façade's storage (lane `store`, round 6)

Frozen 2026-11-11, before any change or measurement. Design: `docs/lanes/core/STORE-R6.md`; departures go in
`docs/lanes/store/DESIGN.md` with their reason.

**Question.** Can the façade keep one element's state in the record's own page (side columns, one index space,
no per-node heap object) so that mounting a row, re-describing it and moving its subtree cost what the core's
23 B record costs, not what seven tables in six index spaces cost?

**Change.** The five stages of STORE-R6: (0) type-stable chunked storage, per-node `Vec`s gone; (1) one index
space (node id = layout id = handle index; `Run` only for multi-instance elements); (2) hot/cold SoA columns
grouped by the pass that reads them; (3) side pages moved by bough-core's page operations through a column
plan folded at monomorphisation, geometry in 1/256 px fixed point, instances at the record's (page, slot);
(4) parallel bulk mount over disjoint pages with a measured grain.

**Workloads** (`crates/bough/examples/redescribe_cost.rs`, instructions on the calling thread, no lock needed):
`MOUNT=1 .. 100 1000 6000` (per row, three row shapes, and an empty App); default mode `10 100 1000`
(re-description per row); `CHURN=1 .. 100 1000` (remove + insert per row); `HEAP=1 .. 1000 6000` (live heap
bytes and allocations per mounted row, per-table bytes); a subtree-move cell added with stage 3.
Frame-path cells at stage boundaries: `bench/integrate/slope.py bough r0 heavy` (stream, scroll), lab both,
animate, `bench/layout/slope.py` (vlist).

**Gates.** After every commit: `cargo check --workspace --all-targets`, `cargo test --release -p bough` (with
`tests/seals.rs`). At stage boundaries: `cargo test --release -p bough-suite -p bough-awagy -p bough-zgui
-p bough-vlist -p bough-heavy -p bough-scenes`. Pixel gates stay exact; no gate is loosened.

**Thresholds.** End state: mount <= 2,500 instructions per application row; <= 300 B of heap per row; a pure
subtree move <= 20 instructions per record; every existing cell <= 1.02x its baseline.

**Negative controls.** For every column plan: a mutant that omits one column from a split/shift must fail a
differential test against a scalar model. For fixed-point geometry: a mutant that rounds instead of floors (or
drops the fractional bits) must fail the ink/edge exactness test. Each new unsafe invariant has a test.

**Stop conditions.** A stage whose gate cells regress past 1.02x and cannot be restructured is reverted and
recorded. If a target is unreachable because the cost is outside the storage (cephal's cold flex pass, the
shaper), say which instructions remain and whose they are, with the profile.
