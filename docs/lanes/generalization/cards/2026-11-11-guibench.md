## Gates and measurement

* Layout check: exact RGB at gui-bench runner points (including row bottom border); save screenshots on failure.
* For every runnable cell, replay inputs through App's host entry points (pointer, key, wheel, tick, resize).
  Never call an operation method directly in the timed driver. Check semantic state against shared spec outside timing.
* Exact presented bytes == full redraw, and retained full redraw == fresh mount of final application state.
  Exercise ring sizes 1, 2, 3, 4 with at least eight changing states; record actual frame/surface use. No tolerance.
  A self-render equality is a damage gate, not independent text raster fidelity.
* Negative control: select additionally scans and black-boxes all row IDs, with unchanged pixels/state. The same
  slope analyzer must flag its O(N) increment over ordinary select. If it does not, locality verdicts are UNKNOWN.
* Instructions: process ri_instructions through `/usr/bin/time -l`, as bench/integrate/slope.py; repeats 8, 32, 128
  operation/undo cycles, three interleaved replicates. Fit instructions vs repeats with an intercept (mount excluded).
  Record every process result and residual, no cherry-picking. Repeats may be reduced only as a labelled amendment
  for resource failure, never silently. Nonpositive slopes or spread >20% are UNKNOWN pending another card.
* Scaling: adjacent log10 ratios and log-log least-squares exponent over positive slopes; use both global and
  largest supported decade. Flag exponent > ideal + 0.20. O(1) cells also flag >2× growth per decade. Limited
  ranges, large fixed overhead and allocation steps do not establish asymptotic proofs. Missing sizes stay missing.
* Resident/physical footprint and mount instructions/time: sample before state construction, after state construction,
  after mount and first frame; report levels and finite-difference bytes/instructions/time per added row. Separate
  process maximum RSS from current RSS/footprint. Font initialization and shader setup remain in mount if inseparable.
* Default capacity is Application::run's APP_CAPS, copied exactly into headless config and labelled. Config::new's
  smaller Caps::DEFAULT is a separate diagnostic, not interchangeable. Never raise either to turn a failure green.
* Child process isolation: panics, aborts, capacity errors, timeouts (120 s/cell), allocation failures and unsupported
  API requests are results. Stop that cell, continue independent cells. Retain stderr and command/provenance privately.
* Hold the shared measurement lock for each complete timing batch; check it before builds/tests. No other heavy
  work during a measurement. Build only needed packages, four jobs, this worktree's target. Check full workspace
  all-targets and run release tests of touched crates before the stage report; report environmental blockers exactly.
* Read assembly for new timed operation loops; distinguish benchmark implementation cost from framework mechanisms.

## Adversarial matrix (predictions before execution)

| case | prediction / falsifiable risk |
|---|---|
| width 4,128 and 6,016×3,384 | 128×32 tile damage width cannot represent the right edge |
| content height 32,800 and 16,777,248 | narrow coordinate saturation and f32 unit precision lose placement |
| 100,000 mounted records | default instances/glyphs/spaces overflow before completion |
| unequal row heights and wrapped labels | height changes rebuild suffix placement beyond changed rows |
| two nested scrolls in a turn | composed spaces/copy history may fail exact repair |
| 200-deep tree | depth representation or recursion bound fails |
| 10,000 signals in one turn | wire/class scans and deduplication may exceed linear union work |
| one signal, 10,000 consumers | linear work required; sparse selection must not pay it |
| CJK, Arabic, emoji, combining marks | no fallback/bidi; self-render gates may pass incorrect text |
| 1,000 front inserts; seeded random moves | Vec order/permutation and height suffix rebuilds accumulate quadratic work |
| owner with 10,000 children, one plain-field change | full re-description walk remains linear |
| scale 1→2→1 | no public live scale entry point; unsupported unless code proves otherwise |
| repeated clear/refill, dead selected slots | deferred reclamation/capacity reuse or stale identity may fail |

Additional probes require an additive prediction amendment committed before their run.
